Put it in Gmail

  1. Press Copy signature.
  2. In Gmail: the gear, See all settings, scroll to Signature, Create new, name it Iconic.
  3. Click into the box and paste. The sigil and icons appear after a moment.
  4. Under Signature defaults pick Iconic for new emails and replies. Keep Insert signature before quoted text ticked.
  5. Scroll down, Save Changes. Send yourself a test.

On the Gmail phone app, signatures are per device: set it once on desktop, and the app uses it when “Mobile signature” is off. Apple Mail and Outlook users: use Copy HTML below and paste into the signature editor, or ask for a hand.
