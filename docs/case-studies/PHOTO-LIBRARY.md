# Photo library

Iconic's hand selected photos, one folder per event, sent as zips on
2026-09-30. Each photo is converted to WebP, resized to at most 2000px on
the long edge, and numbered in the order of the original folder. The
originals stay with Iconic; this file maps each web file back to its
original name.

**Still needed before any photo is published on a page:** photographer
credit and written usage rights, per event (interview protocol, section 5).
