# Interview notes

One file per event, named `<slug>.md`, holding the user's answers in their
own words. Written during the interview, not after, so a session that stops
halfway can be resumed by the next one.

A file here with `full: false` on that slug in `EVENT_INDEX` means the event
was interviewed but its page is not built yet. That is the first thing to
pick up.

See `../INTERVIEW-PROTOCOL.md`.
